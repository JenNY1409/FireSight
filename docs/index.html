Sheet 02

How It Works

01Stabilize & CaptureA 50 Hz complementary filter fuses LSM6DS3TR-C gyro and accelerometer data into a roll/pitch PID loop while the onboard camera captures 128×128 aerial frames.
02Calibrated InferenceOur exported ONNX CNN evaluates each frame across four classes (no_fire, low, moderate, high) using validation-fitted softmax temperature scaling.
03Threshold & TriageFire presence (1 − P(no_fire)) is filtered against confidence thresholds to avoid uncertain false alarms and assign actionable severity levels.

Hardware & CAD

Raspberry Pi + Custom HAT onboard compute & ONNX runtime
Arducam 1080p USB camera day RGB & night near-IR imaging
LSM6DS3TR-C 6-Axis IMU 104 Hz over 4-wire SPI0/CE0
50 Hz Roll/Pitch PID Loop complementary filter + 45° tilt kill-switch
4× Brushless Motors + ESCs pigpio 50 Hz PWM (GPIO 12, 13, 18, 19)
3D-printed housings Pi stack, camera mount, battery bay

Flight safety: The attitude controller clamps throttle, uses derivative-on-measurement to prevent setpoint kicks, and forces an immediate motor disarm if tilt exceeds 45°.

Sheet 04

Model

Instead of brittle color heuristics, FireSight runs a lightweight PyTorch Convolutional Neural Network (small_cnn with GroupNorm blocks, or mobilenet_v3_small transfer learning) exported to fire_model.onnx. Every frame is preprocessed to 128×128 NCHW tensors and scored across four classes.

probs = softmax(logits / T) → [P(no_fire), P(low), P(moderate), P(high)]
P(fire) = 1 − P(no_fire) · severity = argmax(low, moderate, high)
P(fire) ≥ 0.65 = CONFIRMED FIRE · P(fire) ≤ 0.35 = CLEAR · else UNCERTAIN

Calibration: We fit a scalar softmax temperature T on the validation split via L-BFGS and bake it directly into the ONNX graph so confidence thresholds stay reliable across RGB and near-IR sensor domains.

Sheet 06

Testing & Validation

We evaluate the exported model strictly on held-out flight splits (train / val / test) and log per-class precision, recall, confusion matrices, and ordinal severity error to metrics.json.

CUncertain BandAmbiguous frames falling between thresholds, flagged for operator review.
