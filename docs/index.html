FireSight

A small drone that looks down on a forest, spots fire with computer vision, and rates how serious it is, so responders can see which spot needs help first.

How it works

1SeeNight-vision USB camera streams video.
2ThinkA Raspberry Pi 4 runs the vision code.
3DetectA YOLO model boxes fire and smoke.
4ScoreFire size and brightness become a severity level.
5ConfirmAn alert only fires if fire shows in 3 of the last 5 frames.

Try the severity score

This is the same formula the drone’s code uses. Move the sliders to see how a frame would be rated.

score = 0.7 × min(fire share ÷ 10%, 1) + 0.3 × brightness. Below 0.25 is LOW, below 0.55 is MODERATE, and above that is HIGH.

The camera, and what it can’t do

We use an Arducam 1080p USB camera with a day/night filter: normal colour in daylight, a gray infrared-style image in the dark. That helps at night, since fire glows in near-infrared.

It is not a thermal camera, so it can’t measure temperature. Severity is estimated from how big and bright the fire looks, not how hot it is.
